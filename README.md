# Tissue Lab

Interactive tissue classification by Anika Kesavan.

Live website: https://anikakesavan.github.io/tissue-lab/

Real ONNX inference runs in the browser. Held-out image-level test: 143/154 correct (92.9%). Educational research only; not medical diagnosis. See MODEL_CARD.md for evaluation and limitations.

The original cancer-project repository is unchanged. This separate repository hosts the web demo.
